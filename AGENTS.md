# Repository agent guidance

Before designing or changing any game UI, read and follow [`docs/GAME_UI_STANDARD.md`](docs/GAME_UI_STANDARD.md). It is the user-approved baseline for tool grids and pagination, detail scrolling with visible scroll indicators, action-count badges, separated names/quantities, and balanced item density. Check the actual desktop/mobile panel and preserve approved layouts when integrating.

For any game illustration, sprite, animation atlas, terrain tile, weather effect, or pixel-art UI asset, read and follow [`.agents/skills/game-pixel-art/SKILL.md`](.agents/skills/game-pixel-art/SKILL.md) before editing or generating artwork.
